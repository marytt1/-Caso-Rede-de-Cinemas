## Requisitos Funcionais (RF)

### RF01 — Gerenciar Cadastro de Unidades:
O sistema deve permitir o cadastro de cinemas, incluindo nome.

### RF02 — Gerenciar Acervo de Filmes:
 O sistema deve permitir o registro de filmes com informações de título, duração, gênero, elenco e diretor.
 
### RF03 — Programar Sessões:
O sistema deve permitir a criação e manutenção de sessões, vinculando um filme a uma sala/cinema em um horário específico.

### RF04 — Registrar Público:
O sistema deve permitir o registro diário da quantidade de público presente em cada sessão realizada.

### RF05 — Consultar Catálogo:
O sistema deve oferecer funcionalidades de busca de filmes por gênero, elenco ou diretor.
